# 🧬 Neural Evolution Simulation (Neural Game)

Інтерактивна 2D-симуляція природного відбору та еволюції автономних агентів за допомогою штучних нейронних мереж і генетичних алгоритмів на чистому JavaScript.

Агенти існують у динамічному 2D-середовищі, де їхнє головне завдання — знаходити ресурси, виживати та передавати свій «генотип» наступним поколінням. Без використання сторонніх важких ML-фреймворків — уся математика нейронних мереж та симуляція написані з нуля.

---

## 🌟 Ключові особливості

* **Автономне прийняття рішень:** Кожна істота керується власною повнозв'язною нейронною мережею (багатошаровий перцептрон).
* **Генетичний алгоритм:**
  * **Функція пристосованості (Fitness Function):** оцінює тривалість життя агента та кількість зібраних ресурсів.
  * **Селекція (Selection):** найуспішніші агенти мають вищу ймовірність дати потомство.
  * **Кросинговер та мутації:** випадкові точкові зміни вагових коефіцієнтів і зміщень (biases) для дослідження нових поведінкових патернів.
* **Сенсорна система:** Істоти сприймають відстань і напрямок до найближчої їжі та меж середовища, транслюючи ці сигнали у вхідні нейрони.
* **Візуалізація в реальному часі:** Рендеринг за допомогою HTML5 Canvas з високим FPS та плавною анімацією.
* **Zero Dependencies:** Реалізовано на нативному JavaScript без зовнішніх бібліотек.

---

## 🧠 Як це працює

1. **Входи нейромережі (Inputs):**
   * Відстань до найближчого джерела їжі
   * Кут/напрямок до їжі відносно поточного вектора руху
   * Поточна швидкість та рівень енергії
2. **Прихований шар (Hidden Layer):**
   * Обробка вхідних векторів за допомогою функцій активації (ReLU / Sigmoid).
3. **Виходи (Outputs):**
   * Зміна кута повороту
   * Прискорення / швидкість переміщення
4. **Еволюційний цикл:**
   * Кожне покоління живе фіксований час або до загибелі більшості популяції.
   * Кращі особини відбираються для розмноження, формуючи нову популяцію з мутованими вагами.

## 🛠 Технологічний стек

* **Мова:** JavaScript (ES6+)
